# Data Science Crossword

A playable, original browser crossword about programming and data science.

**[Play the crossword](index.html)** (works when hosted on GitHub Pages).

## Features
- Interactive letter grid and numbered clues
- Answer checking with visual feedback
- Reveal and reset controls
- Responsive layout

## Run
Open `index.html` in a browser. No installation required.

## Technologies
HTML, CSS, JavaScript.
