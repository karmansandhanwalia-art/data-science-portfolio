# Crossy Road-Style Arcade Game

A newly reconstructed, playable road-crossing arcade game made with **HTML, CSS, and JavaScript Canvas**. Use arrow keys, WASD, or on-screen buttons to move a chicken across traffic lanes. Cars move in alternating directions; collisions end the round. Earn points for reaching new rows and a bonus for crossing the entire board.

## Run
Open `index.html` in a browser, or use the [live game](./index.html) from GitHub Pages.

## Features
- Keyboard and touch-friendly controls
- Moving obstacles and collision detection
- Score and session-best tracking
- Restart button and game-over state

This is a **new reconstruction**, not the original lost Java project. It is an educational project and is not affiliated with the commercial Crossy Road game.
